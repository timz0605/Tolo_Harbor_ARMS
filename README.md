# Tolo_Harbor_ARMS_Data_Code_Deposit
This is a repository where you can find all R scripts used for bioinformatics and data analysis for the Tolo Harbor ARMS paper. You can also find the raw sequencing data for the project. 

A quick description of the code files
* `Tolo_ARMS_R_script.R` is the main R script, which contains codes for all major figures in the manuscript, including main figures and supplementary figures.
* `site_map_script.R` is the script used to make Figure 1, which is a map showing study sites.
* `spatial_interpolation_script.R` is the script to make Figure 2, which is the spatial interpolation of water quality data.
